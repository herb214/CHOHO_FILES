# CHOHO_FILES · ACS 海外市场情报库

## 海外访问（GitHub Pages）

**首次必做（否则站点 404）：**

1. 打开 https://github.com/herb214/CHOHO_FILES/settings/pages  
2. **Build and deployment → Source** 选 **GitHub Actions**（不要选 Deploy from a branch）  
3. 打开 https://github.com/herb214/CHOHO_FILES/actions → 选中失败的 **Deploy GitHub Pages** → **Re-run all jobs**

成功后访问：

- 地图：https://herb214.github.io/CHOHO_FILES/
- PDF：https://herb214.github.io/CHOHO_FILES/public/qingdao-zhenghe-sample-2026.pdf
- 扫码：https://herb214.github.io/CHOHO_FILES/public/sample-qr.html
