关键观察

1

新上牌里链条在涨，但成熟售后仍是皮带系主场：FENABRAVE 年度份额反映的是「当年新上车牌」的结构，不是全国存量在修结构：巴西成熟车售后仍以干带/湿带等皮带方案为主。同时 2016 起新上牌中链条车型占比已抬升，2016–2025 年均约 53.1%。正时链清单与皮带/湿带产线必须分账。

2

现代 HB20：须按世代（第一代 HB 约 2012–2019，第二代 BR2 约 2019 起）区分配件：同族不同代的张紧器、链条导板不通用。受排放标准升级与排量档税负牵引，Gamma 1.6 在二代约 2022 年后不再供新车，增量与清单主线向 Kappa（尤其 1.0 T-GDI）集中。HB20 与 HB20S 全系链条类配件通用；车系保有量约 70 万台，第一代已进入正时集中更换周期，售后需求充足。

3

VW：EA211 多为主动皮带，EA888 2.0 为链条：Gol / Polo / Virtus / Nivus / Voyage / Up / Taos / Tera 及 Jetta 2015+ 1.4/1.0 TSI（EA211）在映射上为干式正时皮带（O Mecânico EA211、Oficina Brasil T-Cross 1.4 等）。Tiguan 2.0 EA888 等仍为链条体系。避免把 EA211 皮带 BOM 误当链条 TOP。

4

Firefly 平台是 2026-2028 链条放量池：Argo / Mobi / Cronos / Pulse / Fastback 的 NEAR+EARLY 管道厚，1.3T 变体张紧器应力更高，独立 SKU。

VW 皮带集群（不在链条 SKU 盘点内）

Volkswagen 在巴西走量的 Gol、Polo、T-Cross、Virtus、Nivus、Voyage、Taos、Up 及新品 Tera（EA211 皮带）等在映射表上为皮带或湿带方案，市场销量大但应归入皮带售后线。 正时链套装 TOP 榜不包含上述车系；Jetta 2015+ EA211 为干式正时皮带。Tiguan 2.0 等为链条，可单独跟进链条 SKU。

数据口径

· 年份覆盖：FENABRAVE 2003-2025 共 23 年年度累计上牌。
· 链/带年度份额：对 FENABRAVE 全量乘用车行按年汇总，见 fenabrave data/brazil_timing_share_by_year.csv；皮带类含湿式正时带。
· 链条 TOP 榜：仅 timing=chain。皮带、湿带、电驱、PHEV 不进入排名表。
· 映射：按年款 + 车型匹配 `brazil_timing_map.csv`。
· 归一化：品牌别名 (GM→CHEVROLET, VW→VOLKSWAGEN, M.BENZ→MERCEDES-BENZ)、车型别名 (HB 20 S→HB20S) 已合并；同一车型跨代不同正时结构按年款落独立行。
· 打分：Composite Score = 0.50 × ((MATURE+PRIME) / max) + 0.20 × (NEAR / max) + 0.15 × value_tier + 0.10 × 链系统易损归一 + 0.05 × (recent3 / max)，归一化到 0-100。MATURE+PRIME 是「现在就在维修窗口」的绝对主导信号，NEAR 是 12-24 个月管道，value_tier 与链系统易损风险（tensioner_risk 字段）对单价高、且链条/张紧器/导轨/链轮任一子件有已知易损证据的车型加权（TSB、召回、集体诉讼、社区高复发案例），recent3 仅作品牌健康度兜底。
· 源数据 / 脚本：fenabrave_2003_2025_merged.csv, brazil_timing_map.csv；build_parc_analysis.py → fenabrave data/brazil_tc_dashboard_data.json；本页由 gen_brazil_dashboard_assets.py 生成。
· Canvas 源：canvases/brazil-tc-market-update.canvas.tsx — 与本 HTML 数据同源。
· 术语共识：详见仓库根目录 CONTEXT.md。tier 的 S/A/B/C 表示 SKU 优先级；表头车龄桶 NEAR 表示分段保有量，与 C 档非同义。recent3 = 2023、2024、2025 三个日历年新注册合计（FENABRAVE）。tensioner_risk 为关注度参考，不构成寿命或索赔承诺。
