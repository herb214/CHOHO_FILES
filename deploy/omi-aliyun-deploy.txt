海外市场情报库 · 阿里云静态站点（同事通过浏览器访问）
============================================================

一、要上传哪些文件
------------------
在 ECS 上建议固定一个目录，例如 /var/www/omi/，至少包含：

  index.html
  素材/                             （LOGO、装饰图等静态资源，与 index 中路径一致）
  Overseas Market Intelligence/   （整目录：三份大区报告 + 巴西/墨西哥仪表盘等）

若同事还需要打开 tc-parc-dashboard-hub.html，则把该文件一并上传同一目录。

二、安全组
----------
入方向放行 TCP 80（HTTP）；若配置 HTTPS 则再放行 443。
授权对象可先 0.0.0.0/0 验证通过后，再收紧为办公网段。

三、Ubuntu + Nginx（示例）
--------------------------
1) 安装 Nginx
   sudo apt update && sudo apt install -y nginx

2) 上传文件到 /var/www/omi/（用 scp、WinSCP、或 git clone 到该目录均可）

3) 新建站点配置（域名或公网 IP 二选一，下面用下划线占位）：

   可参考本目录 nginx-omi-static.conf ，把 server_name 与 root 改成你的实际值。

4) 启用站点并重载
   sudo ln -sf /etc/nginx/sites-available/omi /etc/nginx/sites-enabled/omi
   sudo nginx -t && sudo systemctl reload nginx

5) 浏览器访问
   http://<ECS公网IP或域名>/index.html

四、HTTPS（可选）
----------------
有域名时可用 certbot 申请 Let’s Encrypt 证书，或使用阿里云「SSL 证书」+ CDN/SLB。
具体步骤以阿里云控制台文档为准。

六、Windows 一键发布（推荐）
--------------------------
在仓库根目录 `Ali_Cloud`（与 `index.html` 同级）打开 PowerShell，执行（默认已与 aliyun-ecs-standard 技能 §0 对齐：IP `8.136.202.129`、密钥 `C:\Ali_Cloud\deploy\Choho_ACS.pem`）：

  powershell -ExecutionPolicy Bypass -File .\deploy\publish-omi-to-ecs.ps1

若要临时换机器或密钥：

  powershell -ExecutionPolicy Bypass -File .\deploy\publish-omi-to-ecs.ps1 -EcsHost <公网IP> -IdentityFile <你的.pem路径>

可选：`-User ubuntu`（若 root 禁登）、`-SkipBootstrap`（服务器已装好 Nginx 时跳过 apt）。

脚本会做：探测 22 端口 → 上传 Nginx 配置与 `ecs-bootstrap-omi.sh` 并执行（安装 Nginx、去掉 default 站点、启用 omi）→ `scp` 同步 `index.html`、`素材/`、`Overseas Market Intelligence/`（若存在则含 `tc-parc-dashboard-hub.html`）→ `chown www-data` 并重载 Nginx。

浏览器访问：`http://8.136.202.129/` 或 `/index.html`。
七、说明
--------
index.html 使用 jsDelivr 加载 d3、topojson 与 world-atlas；ECS 需能访问公网 CDN。
若内网环境禁止出站，需改为把相关 .js / .json 放到同站点相对路径并改 index.html 中的 script 与 d3.json URL。
